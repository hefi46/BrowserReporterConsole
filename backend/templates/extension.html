Google Admin Console Setup
HTTP vs HTTPS: HTTP works for initial deployment but Chrome won't auto-update extensions over HTTP. If you update the extension, you'll need to rebuild and redeploy with a new Extension ID in GAC. Use HTTPS (with CA cert trusted in GAC) for auto-updates.
  1. (HTTPS only) Download the CA Certificate above and upload it in Google Admin Console:
    Devices → Networks → Certificates
    Skip this step if using HTTP.
  2. Build the extension using the button above.
  3. In Google Admin Console, go to:
    Devices → Chrome → Apps & extensions
  4. Click + (Add) → Add Chrome app or extension by ID
  5. Enter the Extension ID:
    Build extension first
  6. Set Installation Policy to:
    Force install
  7. Set Update URL to:
    Build extension first
  8. Under Extension Settings (JSON), ensure:
    { "override_update_url": true }
    Required for self-hosted extensions.
  9. Save. Chrome will push the extension to managed Chromebooks within 24 hours.
