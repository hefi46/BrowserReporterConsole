While serving over HTTP, each new build generates a new Extension ID — Chromebooks will need to be re-configured in Google Admin Console after every rebuild. Once a trusted root CA is deployed to the Chromebooks and the server is accessible over HTTPS, auto-updates will work seamlessly.

Google Admin Console Setup
  1. Go to admin.google.com
  2. Navigate to Devices > Chrome > Apps & extensions
  3. Select the relevant Organisational Unit
  4. Click + > Add Chrome app or extension by ID
  5. Paste the Extension ID above
  6. Set Installation policy to Force install
  7. Set Update URL to the URL above
  8. Paste the managed policy below into the Policy for extensions field
