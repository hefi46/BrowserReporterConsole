How it works

A small PowerShell bootstrap script runs on user login via GPO. It checks this console for updates over HTTP (~50 bytes), only downloads the .exe when the version changes, refreshes the config, and starts the agent as a daemon. The agent runs for the life of the user session, collecting browsing data every few minutes. If the daemon is already running, the bootstrap exits silently.

Deploy Bootstrap Script

The bootstrap script (available in Downloads above) goes on your domain controller's netlogon share. The server URL is automatically set from the config above.

Create GPO Scheduled Task
  1. Open Group Policy Management
  2. Create or edit a GPO linked to the target OU
  3. Navigate to: Computer Configuration → Preferences → Scheduled Tasks
  4. Create a new Scheduled Task with:
    • Trigger: At log on
    • Action: powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File \\dc\netlogon\BrowserReporter.ps1
