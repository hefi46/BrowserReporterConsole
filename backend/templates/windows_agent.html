Deployment Instructions (click to expand)
How it works

A small PowerShell bootstrap script runs on user login via GPO. It checks this console for updates over HTTP (~50 bytes), only downloads the .exe when the version changes, then runs the agent silently. No SMB shares needed.

Step 1: Generate Config

Go to Client Config and click "Generate & Download secureconfig.json".

Step 2: Upload Agent

Build the .exe on a Windows machine and upload it above.

Step 3: Deploy Bootstrap Script

Copy the bootstrap script to your domain controller's netlogon share:

Step 4: Create GPO Scheduled Task
  1. Open Group Policy Management
  2. Create or edit a GPO linked to the target OU
  3. Navigate to: Computer Configuration → Preferences → Scheduled Tasks
  4. Create a new Scheduled Task with:
    • Trigger: At log on
    • Action: powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File \\dc\netlogon\BrowserReporter.ps1
